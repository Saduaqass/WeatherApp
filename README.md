# WeatherApp

Оқу жобасы №8 — «Ауа райы қосымшасы». Kotlin және Jetpack Compose арқылы жасалған шағын Android қолданбасы. Интерфейс қазақ тілінде.

## Мүмкіндіктер

- Open-Meteo Geocoding API арқылы қала іздеу және нақты координаталарды алу.
- Open-Meteo Forecast API арқылы нақты ағымдағы ауа райы және 5 күндік болжам алу.
- Температура, сезілетін температура, ылғалдылық, жел жылдамдығы мен бағытын көрсету.
- Қалаларды таңдаулыға сақтау, таңдау және өшіру.
- DataStore арқылы қараңғы тақырыпты, температура бірлігін және қалалар тізімін сақтау.
- Қазақ тіліндегі ауа райы сипаттамалары және қате хабарламалары.

## Құрастыру

Android Studio-да жобаны ашып, Gradle Sync орындаңыз. Немесе Android SDK орнатылған ортада:

```sh
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Қолданылатын API

- Қала іздеу: `https://geocoding-api.open-meteo.com/v1/search`
- Ауа райы: `https://api.open-meteo.com/v1/forecast`

Күндік болжам үшін `timezone=auto` пайдаланылады. Жеке API кілті қажет емес.
